# ⚡ Phím tắt nhanh 1-Click (Quick Access Scripts)

Thư mục này chứa các file kịch bản `.bat` được tạo sẵn để bạn có thể **nhấp đúp chuột là chạy ngay lập tức** mà không cần mở terminal gõ lệnh thủ công:

---

## 📋 Danh sách các file thực thi nhanh:

### 1. [`1_Chay_Tu_Dong.bat`](file:///d:/TrungHC/AutoCommit/notes/1_Chay_Tu_Dong.bat)
* **Chức năng:** Chạy quy trình AutoCommit tự động bình thường theo cấu hình trong `config.json`.
* **Cách dùng:** Nhấp đúp chuột để chạy. Tự động sinh code giải thuật LeetCode đa ngôn ngữ, rải mốc thời gian xuôi chiều và push lên GitHub.

### 2. [`2_Dang_Ky_Task_Scheduler.bat`](file:///d:/TrungHC/AutoCommit/notes/2_Dang_Ky_Task_Scheduler.bat)
* **Chức năng:** Tự động đăng ký Windows Task Scheduler chạy ngầm hàng ngày.
* **Đặc điểm:** Tự động xin quyền Administrator, cấu hình chế độ S4U (chạy cả khi chưa đăng nhập), thiết lập pin laptop và cho phép nhập giờ chạy tùy chọn (mặc định: `09:30`).

### 3. [`3_Go_Bo_Task_Scheduler.bat`](file:///d:/TrungHC/AutoCommit/notes/3_Go_Bo_Task_Scheduler.bat)
* **Chức năng:** Gỡ bỏ hoàn toàn task chạy ngầm AutoCommit khỏi Windows Task Scheduler.
* **Đặc điểm:** Tự động xin quyền Administrator và gỡ bỏ sạch sẽ trong 1 giây.

### 4. [`4_Bu_Commit_Dai_Ngay.bat`](file:///d:/TrungHC/AutoCommit/notes/4_Bu_Commit_Dai_Ngay.bat)
* **Chức năng:** Bù commit cho cả một dải ngày trong quá khứ khi bị mất chuỗi.
* **Cách dùng:** Nhấp đúp chuột, giao diện sẽ hỏi ngày bắt đầu (ví dụ: `2026-08-10`), ngày kết thúc (ví dụ: `2026-08-20`) và số commit mỗi ngày.

### 5. [`5_Xem_Tro_Giup.bat`](file:///d:/TrungHC/AutoCommit/notes/5_Xem_Tro_Giup.bat)
* **Chức năng:** Hiển thị toàn bộ danh sách các tùy chọn dòng lệnh và tham số nâng cao của AutoCommit.
